# Slink roadmap

This public roadmap describes prospective product work. Shipped behavior is
documented in the README, deployment guide, and release notes.

## Collectors

- GreyNoise Community enrichment
- MISP default feeds
- CISA Cybersecurity Advisories
- abuse.ch SSLBL
- Shodan InternetDB
- PhishTank
- Ransomware.live
- selected national CSIRT feeds

## Product

- Generic notification-channel plug-in interface
- Slack and email notification channels
- Per-user notification preferences
- Scoped personal access tokens
- TOTP and recovery codes
- OIDC single sign-on
- Saved detection-filter presets

## Distribution

- Reproducible signed container releases
- Published deployment conformance tests
- Short dashboard demonstration

Roadmap items are not commitments. Please open an issue before beginning a
large contribution so maintainers can confirm fit and avoid duplicate work.
